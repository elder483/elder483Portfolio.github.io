Overview

This project was a five person week long games jam. My primary roles in this project were lead project, designer and developer.
Additionally I provided some quick meshes such as the boulders and VFX.
The theme for this games jam was rebirth, I decided on an endless runner which features a phoenix.
Submitted as part of the Game Dev Network Games Jam 2021

Problems and Solutions

The Player Character

The initial problem was creating flight controls, the player needed to be able to move the bird vertically and horizontally as the forward movement would be applied directly.
I wanted the bird to turn corners to make the tiles feel more dynamic rather than the bird flying just forward.
The next stage was to get the rebirth mechanic to work, through some playtesting an average of 10 coins would allow the bird to be reborn if they collided with an obstacle.
After this the game needed some pick-ups and abilities. Firstly I created an item dubbed 'flames'. Collecting these flames would give the player an option to either use a smokedash used to pass through an object or fireball to destroy it.
In hindsight the fireball and smoke dash provide a similar outcome, however lava plumes were introduced and as these can't be destroyed the smoke dash gained more usage.

Obstacles

The first problem was to decide what obstacles would be in the cave. Ideally I wanted the objects to feel natural and rather spontaneous rather than creatures appearing.
Boulders would fall from the sky, rocks and some cavern walls had smaller gaps which required the player to fly through small gaps or use an ability to pass the wall.
Lava plumes would shoot a stream of lava vertically which is quite sudden. This requires the player to react quickly.

Story and Level Structure

The story was pretty simple for this game as the focus was about the gameplay.
Various tiles were created and it was meant to be within a volcano, this allowed the team to use the emissive materials and lava to provide light.
